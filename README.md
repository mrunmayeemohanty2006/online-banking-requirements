# 🏦 Online Banking Requirements & Artifacts

> **Automated requirements engineering repository containing end-to-end specifications generated via autonomous AI agent pipelines.**

## 📌 Overview

This repository hosts structured **business, functional, and acceptance testing artifacts** for an online banking platform.

The requirements engineering workflows, document synthesis, and file structures were generated using **Multica's autonomous AI agent pipeline**.

The repository demonstrates how autonomous AI agents can assist in transforming domain knowledge and requirements into structured software engineering artifacts.

## 📂 Repository Structure

```text
online-banking-requirements/
├── brd/
│   └── raw/       # Business Requirements Documents & high-level domain scopes
├── frd/
│   └── raw/       # Functional Requirements Documents, API & system specifications
├── uat/
│   └── raw/       # User Acceptance Testing test cases, scenarios & verification steps
├── sources/       # Baseline domain documentation and prompt context
└── tools/         # Python automation scripts and generation tooling
```

## 📑 Artifact Summary

| Category    | Path       | Description                                                                     |
| ----------- | ---------- | ------------------------------------------------------------------------------- |
| **BRD**     | `brd/raw/` | High-level banking goals, stakeholder flows, compliance, and scope definitions. |
| **FRD**     | `frd/raw/` | Functional workflows, transactional logic, data handling, and edge cases.       |
| **UAT**     | `uat/raw/` | Step-by-step acceptance criteria, scenario matrices, and testing sign-offs.     |
| **Sources** | `sources/` | Baseline domain documentation and contextual inputs used during generation.     |
| **Tooling** | `tools/`   | Automation scripts and document assembly utilities used in the pipeline.        |
